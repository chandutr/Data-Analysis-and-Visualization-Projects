# Data-Analysis-and-Visualization-Projects

This repository contains **different sets of data analysis and visualization projects**, each organized in its own folder.

- 📄 **.ipynb files** – Jupyter Notebook files that include **exploratory data analysis (EDA)** and **data visualization** using Python libraries such as Numpy, Pandas, Matplotlib, and Seaborn.
- 📂 **.csv files** – Dataset files used for analysis and visualization in each project.

Each folder is an **independent project**, demonstrating various techniques for cleaning, exploring, and visualizing data.  
Feel free to explore them individually to learn different approaches to EDA and visualization.
